Deploy Pipeline Update

## Description

This patch updates the AutoPilot Deploy Pipeline on your deployment to the latest version.

## Impact

There is no downtime and no services are restarted.

## Changes

- Updates the AutoPilot Deploy Pipeline to the latest version.

## If You Accept

Deployments from the AutoPilot Deploy Pipeline keep working as the pipeline is improved.
Your sites and deploy steps are not impacted.

## If You Reject

Deployments from the AutoPilot Deploy Pipeline may stop working as the pipeline is improved.

Due `Critical` patch rating, it is not possible to reject this patch.
