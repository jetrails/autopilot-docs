PHP Critical Update

## Description

The PHP project [announced a critical security release](https://www.php.net/archive/2026.php#2026-11-18-1) affecting all supported PHP versions.
Details have not been published yet.
This patch upgrades every installed PHP version and its packages to the latest release.

## Impact

On a single server deployment (All-In-One), PHP-FPM restarts once, which may interrupt requests for a few seconds.
On a Cluster, the web `leader` is used to create an updated boot image and web nodes are replaced using the Auto-Scaling mechanism.

## Changes

- Upgrades every installed PHP version and its packages
- Restarts PHP-FPM on web nodes
- On clusters, backs up the web leader, replaces web nodes

## If You Accept

Your deployment is protected from the vulnerabilities fixed in this release.

## If You Reject

Your deployment stays vulnerable.

Due `Critical` patch rating, it is not possible to reject this patch.
